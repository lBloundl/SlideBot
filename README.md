# Основы управления цифровым продуктом — репозиторий проекта

Шаблон репозитория для курса «Основы управления цифровым продуктом» (Университет Иннополис, 09.03.01 МОИИ, осень 2026).

Весь семестр вы ведёте собственный AI-продукт: от идеи до MVP. Семь домашних заданий — семь частей одного проекта. Этот репозиторий — место, где они живут и куда вы их сдаёте.

## Как начать

1. Нажмите **Use this template → Create a new repository** (или сделайте форк).
2. Назовите репозиторий по своему продукту, например `smart-receipts`, и оставьте его **открытым (Public)** — так преподаватель и одногруппники смогут смотреть и комментировать работы.
3. Пришлите ссылку на репозиторий преподавателю в личку один раз.

Раз репозиторий открытый: не коммитьте ключи API и пароли, а в расшифровках интервью не указывайте имена и контакты респондентов.

## Как сдавать

- Каждое ДЗ — свой файл, шаблоны уже лежат в корне: `dz-01-passport.md`, `dz-02-business-model-jobs.md` и так далее.
- Заполняете шаблон прямо в файле и коммитите. Срок сообщается вместе с каждым заданием.
- Подсказки в шаблонах оформлены как цитаты (`>`). Их можно удалить после заполнения.
- Расшифровки интервью кладите в папку `interviews/`.
- Предыдущие задания после разбора не переделываются. Если замысел поменялся после интервью — это результат исследования, а не провал. Новая версия продолжается со следующего задания.

## Правила

- Проект индивидуальный.
- ИИ использовать можно, в том числе для интервью. Если получится поговорить с живыми людьми — отлично, так вы узнаете больше.
- Практика начинается с разбора ваших работ, поэтому присылайте их до практики.
