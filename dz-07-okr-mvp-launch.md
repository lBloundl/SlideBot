> Последнее задание курса. MVP должен проверять то допущение, которое вы назвали главным в ДЗ-6. Проверяет другое — значит, либо допущение названо неверно, либо MVP собран не под него.

## OKR на квартал

> Цель — состояние, словами, а не числами. Ключевые результаты — 2–4 измеримых исхода из дерева метрик, а не действия.
> Проверка: если ключевой результат можно «сделать», ничего не изменив для пользователя, — это задача. «Выпустить личный кабинет» можно сделать. «Половина новых доходит до первого результата за день» — надо заработать.

### Как будет оцениваться

| | |
|---|---|
| **A** | Цель сформулирована как состояние, ключевые результаты измеримы и не подменены списком задач. MVP заявлен как проверка конкретного допущения из ДЗ-6. Задачи для агентов содержат контекст, ограничения и критерии приёмки. В плане запуска названы первые пользователи и признак успешности |
| **B** | OKR и спецификация корректны, но задачи агентам сформулированы обобщённо; критерии успешности запуска размыты |
| **C** | Ключевые результаты подменены перечнем работ; MVP описан как сокращённый продукт без указания проверяемого допущения |
| **D** | Спецификация MVP отсутствует либо не связана с результатами исследования |
